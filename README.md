# Projects

A monorepo of small, complete tools — each one picked to solve a real problem end-to-end rather than half-finish a big one. No shared build system; each project is self-contained with its own README, dependencies, and run instructions.

| Project | What it does | Stack |
| --- | --- | --- |
| [**CRATEWHEEL**](DJ-track-sorter/) | Sorts a DJ's playlist by musical key (Camelot Wheel) + BPM compatibility via audio analysis, then exports mix-ready Rekordbox XML / M3U. | FastAPI · librosa · React (Vite) |
| [**FPL Team Optimizer**](fpl_optimizer/) | Pulls live Fantasy Premier League data, predicts expected points per player, and solves an ILP to build an optimal squad or suggest transfers. | Streamlit · PuLP (ILP) · pandas |
| [**MovieChat**](moviechatAI/) | Natural-language film/series search ("highest rated korean thriller from the 2010s but not romance") — a hand-built intent parser, no LLM or API key needed for the language part. | FastAPI · TMDB/Watchmode APIs |
| [**Chambers of Law**](chambers-of-law-website/) | Full static website rebuild for a law firm — plain HTML/CSS/JS generated by a zero-dependency Node build script, no framework. | Node.js · vanilla JS |

## Philosophy

Each project favors:
- **No unnecessary infrastructure** — no database or paid API unless the problem actually needs one (CRATEWHEEL is fully stateless by design; MovieChat's language understanding runs locally with zero inference cost).
- **Free-tier-friendly deploys** — Docker/Render/Railway/Vercel/Netlify, chosen deliberately to keep running cost at $0.
- **Honest limitations documented in each README** rather than hidden — what the model doesn't do, what's approximated, and why.
